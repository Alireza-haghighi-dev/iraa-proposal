## Correction to essential requirement 2 (REF-01 §7.2)

**Working wording being corrected:** "Check whether relevant existing solutions or precedents are available in an approved internal collection."

**Why it is corrected:** the English working wording introduced an assumption that the source statement does not support: that an existing, populated and approved internal solutions collection is available.

**Corrected statement of intent:** assess whether relevant existing solution examples can be identified for a submitted need.

**What remains unresolved:**

- which source categories count (records held by the sponsor, external sources, or both);
- whether any dataset is available to the project;
- permissions for using any such source;
- how examples would be retrieved from it.

**What must not be inferred from this correction:** any specific data source, any commitment by the sponsor to supply data, or the existence of an approved organizational solutions database.

**Relation to requirement 4:** requirement 4 already covers external patents and solution examples. Whether requirement 2 also covers external examples, or only sponsor-held ones, is an open question for the owner.

**Identifier:** the requirement keeps its number (R2 in the project registers).

**Recorded:** owner instruction START_STAGE S04.1, 2026-11-20 (project decision DEC-029).
